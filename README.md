# Закрывающий тег

Учебный проект пятого спринта Яндекс Практикума — восемь карточек о пути в изучении вёрстки.

[Открыть сайт](https://saakoz14.github.io/zakrivayuschiy-teg-ad/) · [Репозиторий](https://github.com/Saakoz14/zakrivayuschiy-teg-ad)

## Превью сайта

[![Страница проекта «Закрывающий тег»](./images/preview.png)](https://saakoz14.github.io/zakrivayuschiy-teg-ad/)

## Возможности

- Адаптивная страница с переменной шириной и типографикой.
- Восемь иллюстраций с CSS-фильтрами и подписями.
- Анимированные SVG-сердца и кнопки Like / Unlike.
- Модальное окно сохранения с поддержкой клавиатуры.
- Уменьшение анимации при включённой системной настройке.

## Технологии

HTML, CSS, JavaScript, SVG, вариативный шрифт Inter и пиксельный Press Start 2P.

Основа и макет: [Яндекс Практикум](https://github.com/yandex-praktikum/zakrivayuschiy-teg-ad). Иллюстрации взяты из учебных материалов Практикума.
